# Rebound

Rebound is a calm, local-only daily recovery + wellbeing tracker built with **Expo (React Native) + TypeScript**.

## What’s included

- Bottom tab navigation: **Dashboard**, **Check-In**, **History**, **Settings**
- Local persistence (no login) via on-device storage
- Edit past entries, great empty states, lightweight validation
- Export data as **JSON** and **CSV** via system share sheet

## Run locally

```bash
npm install
npm run start
```

Then scan the QR in **Expo Go** (iOS/Android).

## Notes

- Data is stored **locally on the device** only (no backend).
- Intended to be production-ready structure that you can later distribute to the App Store / Google Play.
